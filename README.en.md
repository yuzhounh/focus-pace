Focus Pace is a modern Windows desktop productivity timer designed around calm, positive accumulation of focused work and refreshing breaks, replacing stressful countdowns.

## Features

- **Forward Time Accumulation**: Tracks actual deep work duration cleanly.
- **Calm Visual Notifications**: Gentle, non-intrusive reminder alerts.
- **Daily Analytics**: Clear charts showing focus vs break ratios.
- **Custom Audio Ambiance**: Integrated white noise and ambient audio sounds.

## Build & Run

```powershell
dotnet build -c Release
```
